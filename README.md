📋 MOM (Minutes of Meeting) Management System

🚀 A full-stack enterprise-level web application to manage meetings, departments, staff, and minutes efficiently.
Designed with ASP.NET Core + SQL Server (Stored Procedures) following real-world architecture.

⸻

✨ Features

🔐 Authentication & Authorization
	•	User Signup & Login
	•	Role-based access (Admin / Member)
	•	Multi-user system (data isolation using UserID)

👤 User Management
	•	Manage user profiles
	•	Upload profile photo

🏢 Department Management
	•	Add / Update / Delete departments
	•	Department logo support

👨‍💼 Staff Management
	•	Manage staff records
	•	Assign staff to departments

📅 Meeting Management
	•	Create and manage meetings
	•	Assign meeting type and venue

📝 Minutes of Meeting (MOM)
	•	Record meeting discussions
	•	Track decisions and outcomes

📊 Dashboard & Reports
	•	Meeting summaries
	•	Data insights
